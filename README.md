# EGereeSignClient

PDF баримтад токеноор гарын үсэг зурах, PDF-ийн гарын үсэг шалгах ширээний програм. Токены драйвер апп дотроо орсон тул Tridum, eSign зэрэг үйлдвэрлэгчийн програм тусад нь суулгах шаардлагагүй.

## Татах

**[Хамгийн сүүлийн хувилбар](../../releases/latest)** хуудаснаас өөрийн компьютерт тохирох файлыг татна.

| Компьютер | Татах файл |
|---|---|
| Mac, Apple Silicon (M1, M2, M3, M4) | `EGereeSignClient-<дугаар>-macos-arm64.pkg` |
| Mac, Intel | `EGereeSignClient-<дугаар>-macos-x64.pkg` |
| Windows 10/11 | `EGereeSignClient-<дугаар>-windows-x86.msi` |

Хэрэв Mac-аа мэдэхгүй бол Apple меню → «About This Mac» дотор «Chip: Apple M…» гэвэл Apple Silicon, «Processor: Intel…» гэвэл Intel.

**Токены драйвер.** Tridum болон ихэнх үйлдвэрлэгч Windows-д зөвхөн 32 битийн драйвер гаргадаг тул Windows-д одоохондоо 32 битийн апп (`windows-x86`) л гаргадаг. Энэ нь 64 битийн Windows дээр ч ажиллана.

## Суулгах

**Mac:** `.pkg` файлыг нээгээд суулгагчийн алхмуудыг дагана. Энэ нь апп болон Tridum, МонПасс токены USB драйверыг хамт суулгана. Mac таны нууц үгийг нэг удаа асууна. Суулгаж дуусаад токеноо залгана. Танигдахгүй бол токеноо салгаж дахин залгана, болохгүй бол Mac-аа restart хийнэ.

**Windows:** `.msi` файлыг ажиллуулна. Админ эрх шаардахгүй, зөвхөн таны хэрэглэгчид суулгана. Шинэ хувилбар хуучнаа солино.

`.msi` суулгаж чадахгүй компьютерт `windows-…zip` файлыг татаад задлаж, доторх `EGereeSignClient.exe`-г шууд ажиллуулж болно.

## Анх нээх үед

**Mac:** `.pkg` болон апп нь Apple-ийн Developer ID-аар гарын үсэгтэй, Apple-ээр шалгагдсан (notarize) тул Mac тэдгээрийг анхааруулгагүйгээр нээнэ.

**Windows:** багц Microsoft-ын кодын гарын үсэггүй тул анх нээхэд Windows «Windows protected your PC» гэж анхааруулна. Тэгвэл «More info» → «Run anyway» дарна. Энэ анхааруулга зөвхөн анх удаа гарна.

## Шинэ хувилбар

Апп шинэ хувилбар гарсныг өөрөө мэдэгдэнэ: үндсэн цонхонд, tray цэсэнд болон Тохиргоо → «Шинэчлэл» хэсэгт «Шинэ хувилбар бэлэн» гэж гарна. «Шинэчлэх» дарахад апп таны компьютерт тохирох суулгагчийг (Mac дээр `.pkg`, Windows дээр `.msi`) өөрөө татаж, файлын хэмжээ, хэш болон Mac дээр суулгагчийн гарын үсгийг шалгаад, хаагдаж суулгагчийг нээнэ. Суулгаж дууссаны дараа апп дахин нээгдэнэ.

Суулгагчаар шинэчилж болохгүй үед (жишээ нь Windows-ийн zip-ээс ажиллуулсан хуулбар, `Applications`-аас өөр газраас ажиллаж буй Mac апп) эсвэл таталт, суулгагч нээх алдаа гарвал «Татах» товч файлыг хөтчөөр татуулна (тохирох файл байхгүй, эсвэл zip хуулбар бол хувилбарын хуудас нээгдэнэ). «Алгасах» дарвал тэр хувилбарын тухай дахин асуухгүй.

## Асуудал гарвал

Апп дотор «Тусламж» → «Оношилгооны тайлан хадгалах» дарж, хадгалсан файлаа хөгжүүлэгчид илгээнэ үү.
