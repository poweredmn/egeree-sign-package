# E-Geree Sign

PDF баримтад токеноор гарын үсэг зурах, PDF-ийн гарын үсэг шалгах ширээний програм. Токены драйвер апп дотроо орсон тул Tridum, eSign зэрэг үйлдвэрлэгчийн програм тусад нь суулгах шаардлагагүй.

## Татах

**[Хамгийн сүүлийн хувилбар](../../releases/latest)** хуудаснаас өөрийн компьютерт тохирох файлыг татна.

| Компьютер | Татах файл |
|---|---|
| Mac, Apple Silicon (M1, M2, M3, M4) | `E-Geree-Sign-<дугаар>-macos-arm64.dmg` |
| Mac, Intel | `E-Geree-Sign-<дугаар>-macos-x64.dmg` |
| Windows 10/11, 64 бит | `E-Geree-Sign-<дугаар>-windows-x64.msi` |
| Windows, 32 битийн апп | `E-Geree-Sign-<дугаар>-windows-x86.msi` |

Хэрэв Mac-аа мэдэхгүй бол Apple меню → «About This Mac» дотор «Chip: Apple M…» гэвэл Apple Silicon, «Processor: Intel…» гэвэл Intel.

**Токены драйвер.** Tridum болон ихэнх үйлдвэрлэгч Windows-д зөвхөн 32 битийн драйвер гаргадаг тул Tridum-ийн токентой бол Windows-ийн `windows-x86` файлыг татна. 64 битийн апп тэдгээрийг ачаалж чадахгүй.

## Суулгах

**Mac:** `.dmg` файлыг нээгээд «E-Geree Sign»-г «Applications» хавтас руу чирнэ.

**Windows:** `.msi` файлыг ажиллуулна. Админ эрх шаардахгүй, зөвхөн таны хэрэглэгчид суулгана. Шинэ хувилбар хуучнаа солино.

`.msi` суулгаж чадахгүй компьютерт `windows-…zip` файлыг татаад задлаж, доторх `egeree-sign.exe`-г шууд ажиллуулж болно.

## Анх нээх үед анхааруулга гарна

Багц Apple болон Microsoft-ын кодын гарын үсэггүй тул анх нээхэд систем анхааруулна. Энэ нь зөвхөн анх удаа.

- **macOS:** «E-Geree Sign cannot be opened…» гэвэл апп дээр баруун товч дарж «Нээх» (Open) сонгоно. Хэрэв «Нээх» гарахгүй бол System Settings → Privacy & Security хэсгээс «Open Anyway» дарна.
- **Windows:** «Windows protected your PC» гэвэл «More info» → «Run anyway» дарна.

## Шинэ хувилбар

Апп шинэ хувилбар гарсныг өөрөө мэдэгдэнэ: tray цэсэнд «Шинэ хувилбар бэлэн» гэж гарч, «Татах» дарахад таны компьютерт тохирох файл хөтчөөр татагдана (тохирох файл байхгүй бол хувилбарын хуудас нээгдэнэ). Апп юуг ч өөрөө татаж суулгахгүй.

## Асуудал гарвал

Апп дотор «Тусламж» → «Оношилгооны тайлан хадгалах» дарж, хадгалсан файлаа хөгжүүлэгчид илгээнэ үү.
